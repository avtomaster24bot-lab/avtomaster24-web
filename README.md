# АвтоМастер24 — веб-версия сервиса (сайт на GitHub Pages)

Тот же сервис, что в Telegram-боте **@TochkaSborki_A24_bot**, только в браузере:
**https://avtomaster24bot-lab.github.io/avtomaster24-web/**

Сайт работает и для **клиентов**, и для **исполнителей** (СТО, эвакуаторы, мойки, магазины запчастей, выездные мастера), и для **администраторов**.
Открывается на телефоне и компьютере. Может работать как Telegram Mini App.

### Тестовые аккаунты на боевой базе (изоляция)

- Тестовые пользователи — только с e-mail в зарезервированном домене `@am24.test` (через Telegram такой не получить).
  Их профили и организации помечаются `is_test`.
- Обычные посетители **не видят** тестовые организации, их цены и отзывы; заявки тестовых клиентов уходят только тестовым

## Обновление 6: роли, права и настройки

Файл базы: **`supabase/08_admin.sql`** (применять после 05 и 07; если 05/07 запускаются повторно — после них снова запустить 08). Только новые объекты `am_*`, повторный запуск безопасен. До применения сайт работает как раньше, новые разделы показывают подсказку «нужно обновить базу».

**Главный администратор** (Админ-панель):
- 👥 **Админы и права** — список админов, назначение регионального админа на город или главного (с подтверждением), снятие прав. Последнего главного админа снять нельзя.
- 👤 **Пользователи** — поиск по имени, @username, телефону; блокировка с причиной и разблокировка; смена роли.
- ⚙️ **Настройки** — общие: лимиты заявок (открытых и в час); по городам: срок жизни заявок по видам, объявление для города на главной. Города — во вкладке 🏙.
- 📜 **Журнал** — кто, что и когда сделал: роли, блокировки, настройки, одобрения и отключения организаций, сотрудники.
- Таблица «Кто что может» для всех ролей.

**Региональный администратор** — то же, но только в своём городе: организации, отзывы, обращения, пользователи и блокировки, настройки города, журнал по городу. Не может назначать админов, менять общие лимиты и справочник городов. На «Обзоре» — карточка с его правами.

**Организация** (Кабинет → ⚙ Настройки, только владелец): пауза приёма заявок, выходные дни, уведомления на устройстве, **сотрудники** по Telegram username:
- *менеджер* — принимает и отклоняет заявки, предложения, чат, поручает заявки, отвечает на отзывы;
- *мастер* — видит только порученные ему заявки, чат и телефон клиента по ним, завершает работу.
Владелец видит, кто принял заявку и кому она поручена, и сколько заявок у каждого сотрудника.

**Клиент** (Профиль): данные и город, уведомления и звук, язык и тема, приватность (экспорт, согласия, удаление).

**Блокировка** работает в базе: заблокированный не может создавать заявки, писать в чат, оставлять отзывы и подавать регистрацию бизнеса; сотрудник с блокировкой теряет доступ к организации. Администратора заблокировать нельзя — сначала снять права.

## Обновление 7: отзывы по закону (`supabase/10_reviews.sql`)

- Рейтинг считается только по **опубликованным** отзывам.
- Модератор не удаляет, а **скрывает** отзыв с пунктом правил (3.1–3.6) и пояснением; автор видит причину и может обжаловать (обращение «Апелляция»).
- По жалобе — «скрыть на время проверки» (п. 5); удалить можно только скрытый отзыв и только с основанием. Все решения — в журнале.
- Автор может удалить свой отзыв или исправить его в течение 30 дней (исправленный снова на модерации; на время проверки править нельзя).
- Владелец и сотрудники не могут оценивать свою организацию.
- Автоматическая отметка возможных персональных данных (телефон, госномер, ИИН, e-mail) — для модератора и предупреждение автору.
- Метка «✔ по выполненной заявке», запрет отзывов за вознаграждение в правилах; годовой отчёт о модерации на странице «Прозрачность» (ст. 13 Закона об онлайн-платформах).

Применять после 09. Пока 10 не применён, сайт работает по-старому (новые функции включаются автоматически). Тесты: `tests/reviews_test.sql`, `tests/e2e/roles_e2e.cjs` (раздел «отзывы»), `tests/e2e/demo_reviews.cjs`.

## Как включить боевой режим (5 минут)

1. Откройте https://supabase.com/dashboard → проект VeloMarket (`wzhwnffdylhkmapijkrn`) → **SQL Editor** → **New query**.
2. Скопируйте весь файл [`supabase/all_in_one.sql`](supabase/all_in_one.sql), вставьте, нажмите **Run**. Должно быть «Success».

4. Сделайте себя администратором: в SQL Editor выполните
   `select am_make_admin('ваш_username_в_telegram');`

   Телефоны организаций в GitHub не попадают (папка `private/` в `.gitignore`).

## Безопасность и личные данные

- В репозитории **нет** токенов, паролей, телефонов и Telegram ID пользователей. Из базы бота взяты только справочники
  (города, 17 направлений и 109 уточнений, услуги, марки, модели, интервалы ТО, справочный прайс).
- В `config.js` только публичный anon-ключ Supabase — он безопасен, потому что в базе включён RLS на всех таблицах.
- Телефон клиента видит **только** исполнитель, который принял заявку (функция `am_client_contact`). Для запчастей поставщики анонимны, пока клиент не выбрал предложение.
- Исполнитель не может сам себе поменять рейтинг, город или включиться после отключения (триггер в базе). Все смены статусов — только через функции с проверками.
